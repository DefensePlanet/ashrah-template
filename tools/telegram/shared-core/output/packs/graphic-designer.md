### Export Specifications

**For Web/Digital:**
- Format: PNG (transparency) or JPG (photos)
- Resolution: 72 DPI (web standard) or 2x for retina
- Color: RGB
- Optimization: Compressed for fast loading

**For Print:**
- Format: PDF (with bleeds) or TIFF
- Resolution: 300 DPI minimum
- Color: CMYK
- Fonts: Outlined or embedded

**For Development:**
- Format: SVG (logos, icons, illustrations)
- Optimization: Cleaned up code, minimal file size
- Responsiveness: Scalable vector graphics
